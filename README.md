# Dev Kumar — Core Infrastructure & Embedded Systems Portfolio

A responsive portfolio focused on core infrastructure, embedded Linux, firmware, high-throughput data paths, and cloud fleet reliability. The animated background topology and host/DPU/NVMe system diagram visualize the hardware-to-service path.

Open `index.html` directly or serve this folder as a static site. GitHub Pages publishes the repository root from `main`.

- `index.html` — portfolio, all 15 resume experience bullets, project links, and architecture diagrams
- `styles.css` — responsive visual design and motion
- `script.js` — animated topology, rotating focus, reveal effects, and project search
- `ROLE_RESEARCH.md` — role analysis, company/product context, and source links
- `.nojekyll` — preserve static asset paths on GitHub Pages
